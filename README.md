💻 Laptop Market Analysis Using Web Scraping and EDA
This project analyzes the laptop market using data scraped from Flipkart. Laptop details such as brand, processor, RAM, SSD, display, price, discount, and ratings were collected using web-scraping techniques.
The scraped data was then cleaned and preprocessed by handling missing values, duplicates, and converting price-related columns into numerical format. Using Exploratory Data Analysis (EDA), I analyzed price distribution, popular brands, RAM/SSD configurations, ratings, discounts, and relationships between different laptop features.
Key objective: To understand laptop market trends, customer preferences, pricing patterns, and brand performance and generate useful business insights from the data.
Technologies used: Python, Jupyter Notebook, Requests, BeautifulSoup, Regex, Pandas, NumPy, Matplotlib, and Seaborn.
